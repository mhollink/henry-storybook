# Henry Hollink

*Voor altijd onze kleine Henry.*

Deze website is gemaakt ter herinnering aan onze zoon Henry. Een plek waar we onze verhalen, brieven, gedachten en
herinneringen aan hem kunnen bewaren en delen met familie, vrienden en iedereen die zijn verhaal wil lezen.

De website is vormgegeven als een warm, geïllustreerd verhalenboek. Geïnspireerd door de magie van Peter Pan en de
speelsheid van Toy Story, twee verhalen die voor ons een bijzondere betekenis hebben.

**Bekijk de website:** [henry.hollink.dev](https://henry.hollink.dev)

## Over het project

De website is een persoonlijke verzameling van verhalen en brieven aan Henry. Sommige verhalen zijn geschreven tijdens
de zwangerschap, andere gaan over de periode daarna, bijzondere momenten of herinneringen die we willen blijven
koesteren.

De inhoud staat centraal. Daarom is gekozen voor een rustige, toegankelijke vormgeving met zachte kleuren, subtiele
illustraties en kleine verwijzingen naar een magische sterrenhemel.

De website is volledig statisch opgebouwd, zonder backend of database.

## Technische opzet

De website is ontwikkeld met:

- **React & TypeScript** voor de gebruikersinterface
- **Vite** voor ontwikkeling en builds
- **React Router** voor navigatie
- **CSS** voor de vormgeving
- **Markdown** voor verhalen en brieven
- **Biome** voor codeopmaak en linting
- **Vitest** voor geautomatiseerde tests
- **Google Analytics 4** voor bezoekersstatistieken, uitsluitend na toestemming

### Lokaal ontwikkelen

Voor het ontwikkelen van de website zijn Node.js en pnpm nodig.

Installeer de dependencies:

```bash
pnpm install
```

Start de ontwikkelomgeving:

```bash
pnpm dev
```

Maak een productiebuild:

```bash
pnpm build
```

### Codekwaliteit

De code wordt gecontroleerd en geformatteerd met Biome.

```bash
pnpm check
pnpm check:fix
```

Voor het uitvoeren van alle controles:

```bash
pnpm verify
```

## Verhalen en brieven

Alle verhalen worden opgeslagen als Markdown-bestanden in `src/content/posts/`.

Ieder verhaal bevat metadata zoals de titel, datum, schrijver, categorie en omslagafbeelding. Hierdoor kunnen verhalen
eenvoudig worden toegevoegd zonder wijzigingen aan de applicatie.

De bestaande verhalen uit de oorspronkelijke website zijn behouden, inclusief hun oorspronkelijke links.

## Privacy en bezoekersstatistieken

Om inzicht te krijgen in het gebruik van de website wordt Google Analytics 4 gebruikt. Hiermee kunnen we bijvoorbeeld
zien hoeveel mensen de website bezoeken en welke verhalen gelezen worden.

Google Analytics wordt pas geladen nadat een bezoeker daarvoor toestemming heeft gegeven.

De website heeft geen gebruikersaccounts en verzamelt geen gegevens via een eigen backend.

## Achtergrond

De eerste versie van deze website ontstond in november 2025, rond Henry's vierde geboortedag. Het was een manier om onze
verhalen opnieuw een vaste plek te geven en herinneringen te bewaren.

In 2026 is de website opnieuw opgebouwd, met meer aandacht voor de vormgeving, leesbaarheid en de bijzondere betekenis
van deze plek.

Hoewel de techniek en het uiterlijk veranderen, blijft het doel hetzelfde: een plek waar Henry's verhaal voortleeft.
